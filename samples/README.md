# 샘플 서류

효과 검증용 더미 문제 10개 × 서류 2개, 참고 서류 3종, 정답표.
설계 기준은 노션 4.2 '기술 스택 결정 & 샘플 데이터' 3장이다. 숫자는 예시다.

- 회사·사람 이름은 가상이고 실제 회사와 겹치는지 검색으로 확인했다. 메일 주소는 예약 도메인(`.example`)이다.
- 폴더 이름의 A는 기준(지난 견적·화주 요청·우리 견적), B는 비교할 것(새 운임·선사 운임·다른 포워더 견적)이다.
- 사진 문제(①⑧⑨)는 `인쇄원본`을 인쇄해 휴대폰으로 찍은 사진을 쓴다. 촬영이 어려우면 `사진(합성)`으로 대신한다.
- `정답표.xlsx`: 문제별 정답(숫자·결론·짚을 칸), 줄별 정답 판정, 읽는 법.

다시 만들기:

```
python3 scripts/samples/build.py    # 서류
python3 scripts/samples/answers.py  # 정답표 (계산 검산 포함)
python3 scripts/samples/verify.py   # 서류 숫자·형식 개수 확인
```

| 형식 | 개수 | 문제 |
| --- | --- | --- |
| 메일(.eml) | 6 | ①③⑤⑥⑦⑨ (스레드: ①⑥⑨, 첨부: ⑦) |
| 글자 PDF | 4 | ②④⑤⑩ |
| 엑셀 | 4 (+첨부 1) | ②④⑥⑧ (+⑦의 첨부) |
| 사진 | 3 | ①⑧⑨ |
| 스캔 PDF | 3 | ③⑦⑩ |
